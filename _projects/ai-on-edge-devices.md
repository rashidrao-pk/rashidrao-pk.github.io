This project focuses on deploying lightweight AI models on edge devices such as **Raspberry Pi**.

## Overview

The goal of this work is to move AI inference closer to the data source by deploying optimized computer vision models on resource-constrained hardware.

## Main Contributions

- Lightweight model deployment on edge devices.
- Real-time computer vision inference.
- Model compression and optimization.
- Raspberry Pi-based AI experiments.

## Applications

- Low-cost AI systems.
- Embedded computer vision.
- Smart cameras.
- Real-time edge inference.

## Technologies

Python · OpenCV · Raspberry Pi · TensorFlow Lite · Edge AI
